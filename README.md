# simitstudio.com

The Simit Studio website, served by GitHub Pages from the root of this repository (custom domain in `CNAME`).

| Address | File |
|---|---|
| simitstudio.com | `index.html` |
| simitstudio.com/couchmouse | `couchmouse/index.html`, with `privacy`, `terms` and `support` beside it |
| simitstudio.com/couch-launcher | `couch-launcher/index.html`, with `privacy`, `terms` and `support` beside it |

Each app gets a folder named after it, with privacy, terms (for paid apps) and help pages.
The privacy and support addresses are in the store listings and inside the apps, so keep them stable.
